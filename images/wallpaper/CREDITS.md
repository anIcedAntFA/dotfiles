# Wallpaper credits

The images here are other people's work, kept so the desktop is reproducible from
a fresh clone. Files are named `<subject>[-<mode>].<ext>`, where `<mode>` is
`light` or `dark`: the **Color-scheme** mode whose `set-wallpaper` hook picks it
(see [CONTEXT.md](../../CONTEXT.md) and [docs/theme-sync.md](../../docs/theme-sync.md)).

[open an issue](https://github.com/anIcedAntFA/dotfiles/issues).
